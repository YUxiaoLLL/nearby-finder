# Contributing / 参与贡献

感谢真实设备测试、文档、无障碍及界面翻译贡献。当前界面主要为中文，中英文 README 不代表 App 已完整双语化。

We welcome real-device reports, documentation, accessibility and UI translation improvements. Bilingual READMEs do not mean the current UI is fully localized.

- Use Issue templates for bugs and compatibility results. Test only your own devices.
- Never post private coordinates, device UUIDs, full serials, credentials or unreviewed logs. Redact images before sharing.
- Distinguish controlled tests from actual recovery and sound from vibration.
- Keep changes focused. Run `bash Check.command` on macOS with Xcode; record what you actually tested.
- Do not add RSSI-to-meter claims, unmeasured bearing arrows, unknown GATT writes or unsupported firmware modifications.
- Do not add analytics, server uploads or background tracking without discussing the data flow and user controls first.
- Public bug reports should describe behavior, not expose personal diagnostics. Private security details should not be posted in Issues; use GitHub private vulnerability reporting if enabled, otherwise ask for a private contact without disclosing the issue.
